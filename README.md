# Titanic_servive-PREDICTION
Machine learning project to predict Titanic passenger survival using Python, Pandas, NumPy, Seaborn, and Scikit-learn.

Titanic Survival Prediction :

    This project uses machine learning to predict whether passengers survived the Titanic disaster. It is based on the Titanic dataset from Kaggle and involves data cleaning, exploratory data analysis, feature engineering, and classification.

Technologies Used :

    Python

    Pandas and NumPy

    Matplotlib and Seaborn

    Scikit-learn

    Jupyter Notebook

Key Features :

    Data preprocessing and handling missing values

    Exploratory data analysis and visualization

    Feature selection and engineering

    Machine learning model training and evaluation

    Passenger survival prediction

Dataset: 

    Kaggle Titanic Competition

Objective :
    To explore passenger data and build a machine learning model that predicts survival based on features such as age, gender, passenger class, and fare.
